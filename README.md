# My Portfolio

A modern portfolio starter with a React + TypeScript client, Node.js + TypeScript server, MongoDB wiring, Framer Motion animations, and React Three Fiber 3D support.

## Structure

- `client` - Vite React app
- `server` - Express API with MongoDB connection plumbing

## Setup

1. Install dependencies at the workspace root.
2. Copy `.env.example` to `.env` and update the values.
3. Start the client and server with the root dev script.

## Scripts

- `npm run dev` - run client and server together
- `npm run build` - build both apps
- `npm run check` - type-check both apps
